# Homebrew tap — Prism Translate

Instalação (um comando; o Homebrew adiciona este tap automaticamente):

```bash
brew install --cask goobinexe/tap/prism-translate
```

Este repositório é o tap Community do [Prism Translate](https://github.com/GoobinEXE/PrismTranslate).
Quando o cask entrar no Homebrew oficial, o comando passará a ser `brew install --cask prism-translate`.
