# Homebrew tap — Prism Translate

Instalação (cole os três comandos):

```bash
brew tap goobinexe/tap
brew trust --tap goobinexe/tap
brew install --cask prism-translate
```

`brew trust` é exigido pelo Homebrew 6 em taps que ainda não estão no catálogo oficial.

Este repositório é o tap Community do [Prism Translate](https://github.com/GoobinEXE/PrismTranslate).
Quando o cask entrar no Homebrew oficial, o comando passará a ser só `brew install --cask prism-translate`.
